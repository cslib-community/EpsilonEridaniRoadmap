# Epsilon Eridani Roadmap

Deprecated in favor of [cslib-frontier](https://github.com/cslib-community/cslib-frontier),
the frontier formalization library for [CSLib](https://github.com/leanprover/cslib).

Propose new work as an
[issue on cslib-frontier](https://github.com/cslib-community/cslib-frontier/issues) rather than
as a pull request to a roadmap repository. Open proposals from this repository are being carried
over to cslib-frontier issues, crediting their authors.
